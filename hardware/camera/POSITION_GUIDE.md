# 白い位置合わせ枠の使い方

「10min・3h」（2026-11-10 19:01:36）の基板外形を候補枠として用意しました。この位置が最適と証明したものではありません。初回に画面上で確認し、位置を登録してください。

## 最初の1回

1. アプリを開き直す。白い枠・中心の十字・UPの印が表示されます。
2. **「拡大／全体」**で見やすい表示にする。拡大は画面表示だけで、保存画像の画角や解像度を変えません。
3. 今の候補位置でよければ、**「位置を登録」→「この枠を保存」**を押し確認します。
4. 今後は各膜の基板外形を白枠に合わせて置きます。枠は膜の色が付いた部分ではなく、基板の外形を表します。

露光・色ゲイン・ピントの設定は変わりません。「基準で調整」を押し直す必要もありません。保存済みの位置枠がある場合はそちらが優先され、候補ファイルで上書きしません。

位置だけ変更したい場合は、次の矢印操作を使ってください。四隅のタップは形や大きさを変更するときだけです。

## 枠の形・大きさを変えずに移動する

1. 「位置を登録」→ **「枠を移動（矢印）」**。
2. ← → ↑ ↓ で枠全体を移動する。調整中はライブ映像を全体表示し、枠の移動が見えるよう表示範囲を固定します。
3. **「粗く 20px」**のボタンを押すと **「細かく 1px」**に切り替わる。単位は保存画像のピクセルで、画面上のピクセルとは異なります。
4. よければ **「保存」**。「取消」なら保存前の枠に戻ります。移動中にアプリを閉じても、未保存の移動は残りません。

露光・色ゲイン・ピントの設定は変更しません。枠が画像の端に届くと、枠全体の移動を止め、四隅を別々に切り詰めたり、枠を縮めたりはしません。移動中は撮影できません。保存した枠は再起動しても残ります。

## 四隅で形・大きさを指定し直す場合

1. 基準として使う場所に膜を置く。
2. 「位置を登録」→「四隅をタップして指定」。表示が静止画になり、登録中は撮影ボタンを使えません。
3. **左上→右上→右下→左下**の順に、基板の四隅をタップ。
4. 確認画面で保存。間違えた場合は保存を断ると4点を指定し直せます。「登録を取消」で元のライブ表示に戻れます。

全体を大きく動かす必要がある場合は、先に全体表示で位置を確認してください。候補枠がある場合、手動指定中はその周囲を拡大します。登録したい対象が拡大範囲の外なら「登録を取消」で戻り、まず候補枠に膜を近づけてから指定してください。

## 記録と注意

- 枠は `~/.config/film_camera/position_guide.json` に保存。変更時は以前のファイルを日時付きでバックアップします。
- 枠は元画像の正規化座標で保存し、画面サイズ・拡大表示・余白に合わせて描画します。
- **JPEGには線・文字・十字を入れません。** 撮影画像はカメラのmainストリームをそのまま保存します。
- JSONの `position_guide` に、使った枠の座標・ハッシュ・候補／登録済みの区別を保存します。
- 枠に合っているかは人が確認します。自動位置判定はなく、JSONのalignment_verifiedはfalseです。
- UPは画面の上方向の印です。四角い基板の180度回転や表裏は検出しないので、ラベルや膜の特徴も使って毎回そろえてください。
- 高さ・傾き・映り込みまでは保証できません。再現性試験は別途必要です。

露光の設定ファイルと位置枠は別です。膜を替えるたびに、どちらも保存し直す必要はありません。
