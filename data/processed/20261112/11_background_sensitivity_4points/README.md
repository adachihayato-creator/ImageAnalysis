# 途中3枚を含める／外す・背景補正あり／なしの比較

[4通りの時系列](01_4通りの比較.png) と [最初・最新の差](02_最初と最新の比較.png)。

問題の途中写真：5分2h 17:53:49、10分2h 17:54:29、15分1h 17:55:16。公称3h/3h/2hは撮り直し後の18:59〜19:01を採用し、さらに19:41〜19:43の3枚を追加。元写真は削除していません。

## 比較の読み方

4通りそれぞれでRGBを実撮影時刻に対して並べ、直線の傾きの符号を記述的に比較しました。途中を除いた場合も3時点を使いますが、統計的な有意性は評価していません。端点の差は途中写真の有無で変わらないため、それだけで「頑健」とは判断しません。

背景補正は固定した紙4領域の平均RGB比を各成分に掛ける簡易補正。補正後も膜の真の色とはみなしません。数値の増減は劣化方向を意味しません。

| 5分 | G | -2.60 | -0.62 | 一致 |

**傾きの方向が一致しても、小さな差を材料変化と認定することはできません。** 同条件・同膜の撮り直し誤差が今回の各時点にないため、検出限界や有意差は設定していません。

## 最新追加後の判断

3膜のB低下、5分のG低下、15分のR増加は4通りで傾きの方向が一致しました。ただし、5分Bなどは途中を含む補正後の傾きがほぼ0で、明確な単調変化ではありません。5分R・10分R/G・15分Gは解析条件で傾きの符号が変わるため保留。微小な数値の符号の一致/不一致に有意性を持たせず、劣化の判定には使いません。

## 模様・色むらの扱い

色むらと細かな模様の補正前結果は[既存グラフ](../09_image_time_series_4points/02_色と模様の経時変化.png)を参照。背景の成分別定数を掛けるだけの補正では、各成分の標準偏差も同じ係数で機械的に変わります。その補正結果を模様の物理的な改善の裏付けにはしません。除外した時点での一時的な模様変化は評価できません。

## XRDとの対応

XRD0h/1hと写真0h/1hを両方持つのは15分膜のみですが、その1h写真が今回の背景問題の対象です。補正あり／なしでの参考比較は残せる一方、問題画像を除くと、この膜の0→1h画像変化とXRD変化の直接比較はできなくなります。したがって「画像変化とXRD変化が対応する」は現段階では保留します。5分・10分は0h写真がなく、最新時点のXRDも未取得です。

各条件1膜の探索解析で、アニール時間の効果・良否・寿命は結論しません。
