# Sn10%膜のXRD：文献との照合（暫定帰属）

対象：FA/Cs系 Sn/(Sn+Pb)=0.10、SnF₂ 0.1 mol%、130℃・5/10/15分、各0h/1h。Cu Kα。FA:Cs＝9:1、公称組成FA₀.₉Cs₀.₁Sn₀.₁Pb₀.₉I₃。ガラス基板、下地なし（ユーザー確認）。同一組成の標準パターンを用いた精密同定ではありません。

[参考位置と実測の比較図](01_相候補の照合.png)

## 現段階の結論

| 実測・角度領域 | 候補 | 判断と制約 |
|---|---|---|
| 約14°・28°の強いピーク | 目的の黒色ペロブスカイト相 | 複数ピークが文献と整合。α相相当の候補だが、α/β等の厳密な対称性は未決定。 |
| 約12.7°付近、特に15分で強い | PbI₂、またはSnを含む残留二価金属ヨウ化物 | 有力候補。Sn–Pb系ではSn_yPb_(1−y)I₂に帰属した例もあり純粋PbI₂と確定しない。 |
| 約11.8°付近 | FA系δ相・他の六方晶ポリタイプ候補 | 背景の盛り上がりと弱い構造があり、独立したピークとしての検証が必要。現状でδ相あり/なしや割合を決定しない。 |
| 約13.2°・26.5°付近 | Cs系δ相、Cs₂SnI₆など | 50%Snの類似系の文献候補。今回10%Snへそのまま適用しない。26°付近は広い背景・周辺構造と重なり、単独帰属不可。 |
| 約53.5°付近 | PbI₂の補助確認位置 | 類似系の文献にある位置を図示。弱い信号のため、これだけでPbI₂を確定しない。 |

**15分の12.75°の強いピークをδ相と呼ぶ根拠は現時点ではなく、まずPbI₂等のヨウ化物候補として扱います。** 10分0hは低角側へ複数ピークがずれており、参考線との絶対位置だけで同定しません。

## 基板条件を踏まえた解釈

ガラス由来の非晶質散乱が広い背景に寄与する可能性があります。特に20〜35°付近の広い盛り上がりを結晶相のピークとして数えたり、全体を膜の非晶質量とみなしたりしません。下地なしのためITO・FTOなどの下地由来ピークは通常の候補から外せます。ガラス単独測定がないので、基板寄与の定量分離や背景の由来の確定はしていません。

## 各膜の見方

- 5分：目的のペロブスカイト相に整合する主ピークがある。12.7°の信号は15分より相対的に弱い。1hの低角側は既存の局所背景法では抽出不成立。不存在の意味ではない。
- 10分：主ピークはペロブスカイト相と整合する候補。ただし0h→1hで約0.3〜0.4°の同方向のずれが複数にある。設置高さ・角度校正も確認し、別相生成や格子変化と即断しない。
- 15分：0h・1hとも12.75°に明瞭なピーク。PbI₂等の副相候補の信号が比較的強いが、相含有率が最も高い/性能が最も悪いとは結論しない。

## 画像解析に使う場合

当面は「約12.7°の副相候補／約14°の主相候補のピーク面積比」という観測指標を使います。「PbI₂含有率」や「α相割合」と名前を置き換えません。既存の局所背景・固定窓による面積は暫定値で、背景・窓幅・測定ずれへの感度を検証する必要があります。画像の色・模様と対応させる探索用で、良否の正解ラベルには未確定です。

FA:Cs＝9:1、ガラス基板・下地なしと確認できました。測定時の設置方法は未確認です。基板単独のパターンや組成に合う構造データによる全パターン照合を行うと帰属を絞れます。相割合の定量には配向・重なり等を考慮した解析が別途必要です。

## 参照した一次文献（2026-11-12確認）

1. [Rombach et al., Nature Communications 16, 5450 (2025)](https://www.nature.com/articles/s41467-025-58489-9)。FA₀.₈₃Cs₀.₁₇Pb₀.₅Sn₀.₅I₃であり今回の10%Snとは異なる。PbI₂に12.8°/53.5°、Cs系副相候補に13.2°/26.5°を対応。全体パターンを擬立方晶ペロブスカイトとして解析。
2. [Triple-cation low-bandgap perovskite thin-films… J. Mater. Chem. A (2020), DOI:10.1039/D0TA07005J](https://pubs.rsc.org/en/content/articlehtml/2020/ta/d0ta07005j)。FA/MA/Cs・Sn50%の比較材料。主ピーク14.1°/28.3°、約12.77°を残留Sn_yPb_(1−y)I₂に帰属。検索取得の本文抜粋で確認、直接ページは403。
3. [Xing et al., Nature Communications 17, 7239 (2026)](https://www.nature.com/articles/s41467-026-73739-0)。FA₀.₉Cs₀.₁PbI₃（Snなし）。FA系δ相の11.8°と、配向を考慮した精密解析の例。
4. [Revealing the impact of ammonium ions… APL Materials 12, 031128 (2024)](https://pubs.aip.org/aip/apm/article/12/3/031128/3277853/Revealing-the-impact-of-ammonium-ions-from)。FAPbI₃（Cs/Snなし）で11.8°δ、12.7°PbI₂、14.0°α。検索取得の本文抜粋で確認、直接ページは取得不可。

各文献の組成・経時条件は今回と異なり、劣化速度や最適アニール時間を転用していません。同一組成と確認できる文献は今回の検索では確保できませんでした。FA:Cs＝9:1が確認され、文献3はAサイト組成が一致しますが、Snを含まないため同一組成ではありません。
