# 外周を除かない解析を採用できるか：追加検証

## 結論

**今回の「明るい斑点候補の面積割合」に限れば、外周18%を一律に除かず、基板全体を主解析に使う根拠が得られました。** 外側にも膜間の違いがあり、全体の斑点面積の5回撮影SDは中央とほぼ同じでした。ただし、全体が常に優れると証明したものではありません。細かな模様や広い色むらでは全体の再現性が低下するため、指標ごとに範囲を選ぶ必要があります。

## 根拠1：外側にも比較に使える違いがある

中央18%除外ROIは164×164=26,896画素、基板全体は65,536画素。外側は38,640画素で、全体の約59%に当たります。中央解析ではこの領域を使っていません。

全体で一度抽出した斑点を領域別に分配した結果：

| 領域 | 5分膜 | 10分膜 | 15分膜 |
|---|---:|---:|---:|
| 中央 | 13.84% | 13.03% | 17.03% |
| 外側（最外周約5%帯を除く） | 11.55% | 11.98% | 14.77% |
| 最外周約5%帯 | 20.75% | 20.86% | 28.15% |
| 全体 | 14.27% | 14.12% | 18.28% |

**基板の最も端に近い帯を除いた外側にも、15分膜で斑点候補面積が大きい違いがありました。** そのため、全体の違いが基板の最端の反射だけで生じたとは言えません。ただし外側の明るい領域を化学的に同定したわけではなく、膜形成状態と断定はしません。

15分−10分の斑点画素数の差は全体で2,722画素。その内訳は中央1,075、外側（最外周帯を除く）726、最外周帯921画素です。全体の差には最外周も約34%寄与しており、縁・反射の影響を無視できるという結果でもありません。これは画素数の内訳で、原因の寄与率ではありません。

## 根拠2：斑点面積の撮り直しSDはほぼ同じ

同じ10分膜の5回撮影に同じ色補正・抽出条件を適用し、中央と全体を比較：

| 指標 | 中央 | 全体 |
|---|---:|---:|
| 斑点面積割合の撮影間SD（ポイント） | 0.2093 | 0.2077 |
| 斑点面積割合の最大−最小（ポイント） | 0.4796 | 0.5203 |
| 細かな模様指標の撮影間SD | 0.0013 | 0.0028 |
| 広い明るさCVの撮影間SD | 0.0032 | 0.0147 |

**斑点面積のSDは中央0.209、全体0.208ポイントで、今回の5回では全体にしても大きくなりませんでした。** 全幅は中央0.480、全体0.520ポイントで、全体がわずかに大きい値です。同等性検定や信頼区間の検証はしておらず、「完全に同じ精度」とは言いません。10分膜の短時間試験だけの結果で、5分・15分や長時間の撮影精度を保証しません。

一方、細かな模様・広い色むらのSDは全体で大きくなりました。斑点面積の結果を他の画像特徴へそのまま広げないことが重要です。

## 根拠3：膜間の違いは全体でも維持された

同じ主条件で各範囲を別々に斑点抽出すると、15分と他2膜の大きい方との差は中央3.171ポイント、全体4.012ポイントでした。全体では違いが消えず、絶対差がやや大きくなりました。補正あり/なし、局所平均幅3通り、しきい値3通りの18設定では、中央・全体とも18/18で15分が最大。外側（最外周帯を除く）は14/18で15分最大でした。全体だけが安定という結果ではなく、中央でも同じ順位を得られます。

設定数は独立した膜数や分類精度ではありません。膜間差と10分膜の撮影SDの比もCSVに残しましたが、統計的な効果量や有意差としては使いません。強い副相候補ピークを持つ独立膜が1枚のため、判別性能は評価できません。

## 採用方針

**明るい斑点候補の面積割合は、基板全体を主解析にし、中央・外側・最外周帯を併記する**方針が今回の結果と整合します。外周を一律18%除く必要性は今回の斑点面積では示されず、外側の特徴を捨てない利点があります。最外周帯は反射等の可能性を残し、これだけの信号を相の指標とはしません。細かな模様・色むらについては中央解析も維持します。

発表での表現例：

> 外側にも副相候補ピークの強い15分膜に特徴的な斑点分布が見られた。また、10分膜の5回撮影における斑点面積割合の標準偏差は、中央0.209、全体0.208ポイントでほぼ同程度だった。このため、斑点面積の評価には外周を一律に除かない全体解析を採用し、縁の影響を領域別集計で確認した。

## 方法と制約

公称1hの3膜と、別時点の10分膜の5回技術反復を使用。標準偏差は標本SD（ddof=1）。基板四隅で256pxへ整形。共通の背景基準は5分膜1h、各成分の紙RGB比で補正。局所明暗差10%超、Gaussianσ8px、連結3画素以上。補正なし/σ6・8・12/閾値5・10・15%を感度確認。

中央＝各辺46pxを除く領域、最外周帯＝各辺13px(約5%)、外側＝中央の外。最外周帯は反射を直接検出したマスクではなく、感度確認の便宜的区分です。5%が最適だと示す解析ではありません。基板全体には裸のガラス・縁・反射・傷が混ざり得ます。

領域比較は2種類を区別：primary_regions.csvは各マスク内で成分を抽出し直すので、以前の中央/全体比較と一致。partition_of_full_detections.csvは全体の同じ抽出結果を分配し、画素数の内訳が加算可能。境界をまたぐ連結成分の扱いで、中央面積は両方式で僅かに異なります。

原本の変更・削除なし。全数値、入力ハッシュ、設定はCSV/JSONに保存。XRDの新規解析はしておらず、1hの15分膜が副相候補ピーク大という既存の対応を使用。
