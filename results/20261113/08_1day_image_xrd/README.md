# 1日後までの画像・XRD解析

既存の方法を変えず、3膜の1日後を追加。XRDは0h/1h/5h/1dayの12測定、画像は各膜6時点の18枚。1dayはユーザー指定の公称ラベル。XRD装置時計は比較に使用していません。

## 結果：1h → 1日後

| 膜 | 斑点候補面積率（全体・補正後） | 副相候補／主ピーク面積比 |
|---|---|---|
| 5分 | 14.27% → 14.44% | 抽出不成立（ゼロではない） → 抽出不成立（ゼロではない） |
| 10分 | 14.12% → 14.07% | 0.084–0.118 → 0.022–0.032 |
| 15分 | 18.28% → 15.45% | 0.548–0.610 → 0.345–0.388 |

15分膜では斑点候補面積率が約2.83ポイント低下し、XRDの相対面積比も低下しました。画像の減少は補正あり／なし、外周除外0／5／18%の6条件で共通しています。単に外周を含めた場合だけに現れる結果ではありません。ただし、反射・ピント・画角位置等を完全に分離したものではありません。

10分膜はXRDの相対面積比が下がりましたが、全体の斑点面積率はほぼ横ばいでした。外周5%・18%除外では小幅増加となるため、画像の小さな増減の方向は領域依存です。1日後の副相候補抽出は3種類の背景のうち2種類でのみ成立する弱い信号であり、精密な減少率は示しません。

5分膜は斑点面積率がほぼ横ばい。XRDの副相候補は1hも1日後も抽出不成立であり、「存在しない」「ゼロ」とは言えません。

1日後も15分膜は3膜中で斑点面積率とXRD相対面積比がともに最大です。ただし、1h時点の斑点面積率の差は縮小しました。膜同士の順位の対応は残っていますが、全膜の時間変化を斑点だけで説明する共通の関係は確認できません。

## XRDの解釈上の限界

面積比は約12.7°候補ピークを約14°主ピークで割った相対指標です。低下はPbI₂の絶対量低下や相含有率低下を証明しません。主ピーク強度・配向・測定位置・背景の影響を含みます。主ピークの見かけ半値幅は1h→1dayで5分0.466→0.340°、10分0.341→0.394°、15分0.363→0.308°と膜ごとに異なります。装置幅補正なしなので結晶性や結晶粒径の断定には使いません。

各条件1膜、独立膜数3。統計的な相関の立証、予測モデル、斑点の化学相同定、良膜判定は行っていません。
