# 5分膜の向き確認

18:56:22の写真と16:37:01の5分膜を基板四隅で256pxへ整形して比較。中央領域の帯域画像（Gaussian σ2−σ10）の相関は、最新像を反時計回り90°回した場合0.908、鏡映ありの最高0.226でした。相関は確率ではなく探索的な比較値です。

最新像は以前と比べ、画像上で時計回り約90°の向きと判断します。膜の非対称な模様も一致します。裏返しの必要な左右反転より回転のみがよく一致するため、以前と同じ面を撮影している可能性が高いですが、膜面側かガラス側かの絶対判定は写真だけではできません。ガラス越しにも膜の模様が見えるため、確認済みの基準や基板端面の観察等が必要です。

これは向き確認用撮影として保存し、成膜後時点は未指定のため経時解析には加えていません。元写真はdata/raw/試行錯誤写真/photo_20261112_185622_645764.jpg（対応JSONあり）。比較図comparison.png、全8変換の値orientation_scores.json、再生成コードnotebooks/film_time_series/check_sn10_orientation.py。
