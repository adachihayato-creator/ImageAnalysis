# XRDと画像の対応整理

28測定を10膜へ対応付け。ユーザー確認済みの膜番号で整理。元ファイル名は維持し、TXT/RASXの数値全点一致に基づいてペアリング。XRD時刻から390秒を引いた開始/終了時刻を使用。

Sn10・膜2は初回RASXと1h名のTXT、1hRASXと無時点名のTXTを同じ測定として保存。時間順でも確認。Touma Snなし膜1の最後はRASX3h/TXT3.5hの名称不一致が残るためmeasurement_03_3h_or_3.5hへ保存。初回XRD開始から約196分だが、初回開始が正確な成膜終了時刻ではないため3h/3.5hを時刻だけで断定しない。

対応表には同じ膜の最も近い画像（時差の正負あり）と、測定終了後の最初の画像を別々に記載。同じ公称時間だけで紐付けず、同時測定ともみなさない。画像が前の場合は測定前候補として明示。後続画像がなければ空欄。候補は自動的に機械学習用の正解ペアとして確定しない。

追記：ユーザー確認によりTouma Snなし膜1の最後の測定は3.5hで確定。フォルダをmeasurement_03_3.5hへ変更。元RASXの3hというファイル名は原本維持のため変更なし。
