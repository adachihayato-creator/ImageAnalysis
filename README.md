# ABX3ペロブスカイト太陽電池 画像解析プロジェクト

このリポジトリは、ABX3構造を持つペロブスカイト太陽電池（FAMACsPb(IBr)3やIBACl、RbCl等）の結晶薄膜における、RGB分布解析・結晶性評価を行うための画像解析プログラム群です。

## 📂 フォルダ構成

```text
ML/
├── notebooks/          # 解析実行用のJupyter Notebook
└── data/
    ├── raw/            # 実験で得られたオリジナル画像（※Git管理対象外）
    └── processed/      # プログラムによって出力された解析後のグラフやデータ
